The Pipeline

How It Works

A transparent, step-by-step RAG pipeline with zero black boxes.

Step 01

Query Routing

Your question is classified by a LangGraph router node into one of 5 workflow types based on intent signals extracted from the query.

Step 02

Hybrid Retrieval

Qdrant vector DB performs dense semantic search while BM25 handles exact keyword matching. Results are fused and re-ranked by relevance.

Step 03

Relevance Gating

Retrieved chunks pass a relevance threshold. If no sufficiently grounded evidence exists, the system hard-refuses to generate an answer.

Step 04

Grounded Generation

Qwen 2.5 generates a structured scholarly response conditioned only on retrieved context, with explicit inline citation markers throughout.
